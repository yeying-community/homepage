夜莺钱包使用手册

安装与创建钱包

从夜莺官方入口打开 Node 应用中心，按页面提供的安装方式获取钱包扩展。安装后将扩展固定到浏览器工具栏，再打开钱包创建新账户或导入已有账户。

  1. 确认浏览器地址为官方域名 wallet.yeying.pub 或 node.yeying.pub，再从 Node 应用中心进入钱包。
  2. 创建钱包时设置本机密码，并按钱包提示完成助记词备份；导入钱包时核对恢复后的账户地址。
  3. 首次使用前先确认当前网络、账户地址和安全备份，再进行连接或转账。
打开 Node 应用中心

账户、网络与转账

  • 从主页面的账户区域切换账户或打开账户管理；复制地址或查看二维码前，先核对当前账户。
  • 收款和转账前确认当前网络。相同格式的 EVM 地址不代表资产属于同一条链。
  • 收款时向对方提供正确网络下的账户地址，并先用小额转账测试新地址或大额收款。
  • 转账前核对网络、资产、接收地址、金额和手续费。发送 ERC-20 通证也需要对应网络的原生资产支付 gas。
  • 可在“网站管理”查看和撤销 DApp 授权；撤销授权不会影响链上资产。

安全与密钥

助记词和私钥就是资产控制权

不要把助记词、私钥或钱包密码发送给任何人，也不要输入到网页、客服表单、聊天工具或云文档。夜莺支持人员不会索取这些信息。

  • 钱包密码用于保护本机钱包数据；忘记密码后，必须使用有效备份和对应密码恢复。
  • 连接网站只会按授权提供账户或身份资料；签名前先检查来源、请求内容和权限范围。
  • 转账前逐项核对网络、接收地址、资产和金额。首次或大额转账建议先做小额测试。

备份与恢复钱包

账户备份文件和云端密钥托管是不同的恢复入口。普通数据同步不包含私钥，不能代替账户或身份恢复。

导出加密备份文件

  1. 在钱包中打开“账户管理”，选择“导出所有账户”，按提示输入钱包密码。
  2. 将导出的加密 JSON 文件保存在自己控制的安全位置。文件仍需密码才能恢复，不要公开分享或上传到不可信服务。

在新设备恢复

  1. 安装夜莺钱包，选择“导入钱包”，切换到“备份文件”，再选择此前导出的 JSON 文件。
  2. 输入导出该文件时使用的钱包密码，等待钱包完成解密、格式和完整性校验。
  3. 解锁后核对账户地址和 Wallet Identity DID。只有地址和 DID 都符合预期后，再继续使用或签名。

如果忘记身份材料仍使用的旧钱包密码，可以选择仅恢复钱包账户；这种情况下原 Wallet Identity 的签名能力不会恢复。请在页面确认恢复结果后再继续。

云端密钥托管恢复

如曾主动开启云端密钥托管，在新设备选择“云端恢复钱包”，使用绑定该身份的通行证完成 Node 授权，再输入创建托管记录时使用的原钱包密码。钱包会在本地解密密文并校验地址与身份。托管端只保存加密快照；Passkey 或 Node 授权本身不等于私钥。

恢复完成后，使用原 DID 发起一次钱包身份登录，确认 DApp 收到的身份与恢复前一致。不要把 WebDAV 数据同步当作密钥备份。

钱包身份登录

钱包身份让你用同一个 DID 登录支持该协议的应用。每个应用必须单独请求所需资料范围，钱包会在确认页展示应用来源和权限。

  1. 确认发起请求的网站域名和应用名称。
  2. 检查它请求的资料范围，例如基础身份、关联钱包、用户名或邮箱；只批准你愿意提供的范围。
  3. 钱包为当前应用和本次请求生成身份出示证明。应用后端应校验 DID 签名、audience、nonce、scope 和有效期。

恢复钱包后首次身份登录若要求解锁，请在钱包中输入本机密码继续。身份 DID 与恢复前不一致时，先停止操作并检查导入结果。

开发者：接入 DApp

地址连接使用 EIP-1193 Provider；钱包身份登录使用 Wallet Identity 协议。站点应在用户操作后发起请求，并由钱包展示确认界面。

const accounts = await ethereum.request({ method: 'eth_requestAccounts' })

const presentation = await ethereum.request({
  method: 'wallet_identity_presentation',
  params: [{ audience, nonce, scopes }]
})

后端必须验证签名、应用 audience、一次性 nonce、批准的 scope 和有效期，不能只相信前端返回值。

故障排查

备份文件密码不正确
请使用导出该文件时的钱包密码。它可能与新设备上当前使用的密码不同。
恢复后 DID 与原来不同
请停止身份登录，确认选中的是恢复出的身份，并重新检查备份文件和账户地址。
DApp 检测不到钱包
确认钱包扩展已安装并解锁，刷新 DApp 页面，再通过官方入口联系支持人员。不要向任何人发送助记词或私钥。
